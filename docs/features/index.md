# OpensourceERP — Feature-Dokumentation

Übersicht aller Features mit Anleitungen zur Einrichtung und Verwendung. Jede Seite trägt Metadaten (Titel, Kurzbeschreibung, Gruppe, Erweiterung, Rubrik); daraus entstehen die Navigation im System und der Feature-Katalog für die Website.

> **[Gesamtübersicht aller Features](alle-features.md)** — vollständige Aufstellung von Kernsystem und Erweiterungen in einem Dokument.
