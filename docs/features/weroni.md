# Weroni — KI-Assistent

Weroni ist der integrierte KI-Assistent von OpensourceERP. Er hilft bei Fragen zum System, analysiert Daten und kann Aufgaben ausführen.

## Funktionen

- **Konversation**: Natürliche Kommunikation in deutscher Sprache
- **Datenanalyse**: Fragen zu Kunden, Umsätzen, Aufträgen etc. beantworten
- **Dokumentenanalyse**: Hochgeladene Dokumente analysieren und zusammenfassen
- **Aufgaben**: Aktionen im System vorschlagen und nach Bestätigung ausführen
- **Rückfragen**: Bei kritischen Aktionen wird vor der Ausführung nachgefragt

## Verwendung

Weroni ist über das Chat-Icon in der Navigationsleiste erreichbar. Nachrichten werden als Konversation gespeichert.

### Aufgaben bestätigen

Wenn Weroni eine Aktion vorschlägt (z.B. "Soll ich diesen Kunden anlegen?"), kann diese:
- **Bestätigt** werden → Aktion wird ausgeführt
- **Abgelehnt** werden → Mit optionaler Begründung

Dringende Rückfragen werden als Benachrichtigung in der Infoleiste angezeigt.
