{{- /* Bindet das Widget-Bundle ein. Wird von jedem Widget-Shortcode aufgerufen — das ist unschaedlich: ein ES-Modul wird pro URL genau einmal geladen und ausgefuehrt, auch wenn das script-Tag mehrfach im Dokument steht. Der Fingerprint im Dateinamen ist Pflicht, weil nginx .js-Dateien mit "expires 1y; immutable" ausliefert. Ohne ihn wuerde eine neue Bundle-Version bei wiederkehrenden Besuchern ein Jahr lang nicht ankommen. Theming: das Preset bestimmt, welche CSS-Klassen die Widgets vergeben und welches Stylesheet sie in ihren ShadowRoot adoptieren. Konfiguration in der Site-Config, z.B. "params": { "shopui": { "theme": "bootstrap5" } } "params": { "shopui": { "theme": "pure" } } "params": { "shopui": { "theme": "tailwind", "stylesheet": "/css/site.css" } } "params": { "shopui": { "theme": "custom", "stylesheet": "/css/shop-ui.css" } } Ohne Angabe gilt "bootstrap5"; das Stylesheet wird dann automatisch aus dem bereits geladenen der Seite ermittelt. Einzelne Rollen lassen sich pro Shop ueberschreiben — vor allem bei Tailwind noetig, weil dort die Farben in den Klassen stecken: "params": { "shopui": { "theme": "tailwind", "classes": { "buttonSecondary": "inline-block rounded px-4 py-2 bg-teal-700 text-white" }}} */ -}} {{- $cfg := site.Params.shopui | default dict -}} {{- /* Pfade der Shop-Seiten (shop-ui/src/core/paths.js): Ein Shop kann unterhalb einer bestehenden Webseite liegen, etwa https://werkstatt.example/shop/. "params": { "shopui": { "paths": { "base": "/shop/" } } } "params": { "shopui": { "paths": { "base": "/shop/", "cart": "korb/", "login": "/anmelden/" } } } base Basispfad des Shops ab der Wurzel der Domain. Vorgabe: der Pfad der baseURL — liegt die ganze Hugo-Seite unter /shop/, stimmt er ohne Angabe. api Adresse des Weiterleiters. Vorgabe: shop-api/ — er liegt in static/ der Hugo-Seite, nicht unter base. Seiten cart, checkout, invoice, paymentcanceled, login, logout, register, registered, account, profile, addresses, orders, payment, categories, searchresults, contactthanks, privacy, home — relativ zu base, oder mit / ab der Wurzel. Ohne Angabe die Vorgaben der Widgets (warenkorb/, kasse/, rechnung/ …).
